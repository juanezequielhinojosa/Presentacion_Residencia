Diapositiva 01 / 05 Desarrollo Frontend con IA

Portada y El Desafío del Frontend

Concepto central: Pasar de la base de datos en la nube a lo que ve y toca el usuario (la tienda web).

  • ⚠️
    El Problema

    Codificar una SPA (Single Page Application) desde cero en pocas horas es imposible para un emprendedor sin un equipo entero de desarrollo.

  • ✨
    La Solución

    Inteligencia Artificial Generativa (Google AI Studio) combinada con el stack moderno de React 19 + Vite + Tailwind CSS.

  • 🎯
    El Objetivo de la Clase

    Tener la interfaz lista, conectada a la base de datos en Supabase y vendiendo por WhatsApp antes de terminar la clase.

Analogía del Taller Maker

🍨 Clase 1 (Ayer): Creamos la heladería y llenamos la heladera con productos en Supabase.

🏪 Clase 2 (Hoy): Vamos a construir el local, las vidrieras iluminadas y la caja registradora usando IA para no tardar meses en programar cada botón.

Desarrollo Asistido por IA (Prompt Engineering)

Concepto central: Cómo darle instrucciones claras a la Inteligencia Artificial para que construya exactamente lo que necesitamos.

  • 🧩
    Prompt Estructurado

    La fórmula profesional: Rol (Experto Frontend) + Contexto (Taller 3D Maker) + Tarea (Catálogo reactivo) + Restricciones técnicas (Sin frameworks pesados).

  • ⚡
    Tecnologías Solicitadas a la IA

    React 19 + TypeScript + Vite + Tailwind CSS para garantizar código tipado, modular y de altísima velocidad de carga.

  • 🔑
    Inyección de Credenciales

    Conexión directa mediante las credenciales obtenidas en la Clase 1: SUPABASE_URL y SUPABASE_ANON_KEY.

Ejemplo de Prompt Estructurado
1. ROL: Desarrollador Frontend Senior especializado en E-Commerce React.
2. CONTEXTO: Taller de impresión 3D "Universo 3D" con catálogo en Supabase.
3. TAREA & RESTRICCIONES: Construye una SPA con Vite, buscador instantáneo y checkout que formatee un mensaje hacia WhatsApp.
❓ Pregunta disparadora: ¿Qué pasa si le pedimos a la IA que cree una tienda de ropa en lugar de una de productos 3D? ¿Cómo corregimos el rumbo?
La IA asumirá talles, telas y prendas genéricas. Para corregir el rumbo con un nuevo prompt, no empezamos de cero: le damos feedback especificando el dominio exacto (piezas mecánicas, filamentos PLA+, horas de impresión y archivos STL) y le adjuntamos el esquema exacto de nuestra tabla productos de Supabase para que modele las tarjetas a medida.
🎙️ Palabras del Docente / Analogía

"La IA es como un programador senior hiperactivo pero literal: si le das un prompt pobre, te devuelve cualquier cosa. Si le das un prompt con la estructura exacta de nuestra tabla Supabase, te arma la tienda perfecta."

Consumo de la API y Estado Local (El Catálogo)

Concepto central: Cómo viajan los datos desde la nube hasta la pantalla del cliente.

  • 🔄
    Petición Inicial (fetch / SDK)

    Al abrirse la tienda, el frontend ejecuta una consulta asíncrona hacia Supabase (.from('products').select('*')) y almacena los ítems en memoria.

  • ⚡
    Filtros Instantáneos en el Navegador

    Búsqueda en tiempo real por texto, material (PLA, PETG, Resina) y categoría sin recargar la página ni saturar el servidor.

  • 💾
    Persistencia Local (localStorage)

    El carrito de compras y las cantidades seleccionadas se conservan en el navegador. Si el usuario recarga la página, su pedido no se pierde.

Arquitectura del Catálogo
// 1. Carga inicial desde Supabase
const { data } = await supabase.from('productos').select();

// 2. Guardar en localStorage
localStorage.setItem('universo3d-cart', JSON.stringify(cart));

✓ Respuesta a 60fps sin latencia de red
🎙️ Palabras del Docente / Analogía

"El catálogo de Supabase se descarga de golpe al entrar a la página; después, los filtros y el carrito funcionan de manera local en la computadora del cliente para que la respuesta sea inmediata."

Cierre de Venta Directo por WhatsApp (wa.me)

Concepto central: El modelo de negocio de bajo costo (sin pasarelas de pago complejas).

  • 📲
    Formato del Mensaje Estructurado

    Fecha y hora, datos del comprador (nombre, entrega), listado numerado de ítems, precio unitario, subtotales y total general a pagar.

  • 🔗
    Enlace Dinámico URL

    Uso del protocolo oficial: https://wa.me/<número>?text=<mensaje_codificado> sin instalar plugins de terceros ni pagar comisiones bancarias.

  • 🎯
    Pantalla de Éxito / Feedback

    Opciones tras el envío para reabrir WhatsApp si hubo bloqueo de popups, copiar el resumen en texto plano o vaciar el carrito para un nuevo pedido.
